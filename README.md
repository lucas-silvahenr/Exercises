# Exercícios de Programação

Este repositório reúne exercícios de programação resolvidos ao longo dos meus estudos, prática diária e desafios técnicos.

O objetivo é manter um histórico público da minha evolução como desenvolvedor, documentando não apenas as soluções implementadas, mas também o raciocínio utilizado para resolver cada problema. Sempre que possível, os exercícios incluem descrições, explicações sobre a abordagem adotada e o código-fonte correspondente.
