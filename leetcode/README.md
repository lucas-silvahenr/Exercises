
# LeetCode

Esta pasta contém minhas soluções para problemas do LeetCode.

O objetivo é registrar meu progresso na plataforma, praticar algoritmos e estruturas de dados, além de documentar o raciocínio utilizado para resolver cada desafio.

## Estrutura dos Exercícios

Cada exercício possui sua própria pasta identificada pelo número do problema e seu nome em formato *snake_case*.

### Exemplo

```text
013-roman_to_integer
├── description.md
├── main.py
└── solutions.md
```

### Arquivos

| Arquivo          | Descrição                                                                        |
| ---------------- | -------------------------------------------------------------------------------- |
| `description.md` | Resumo do problema, informações relevantes, exemplos e restrições.               |
| `solutions.md`   | Explicação da solução implementada, incluindo raciocínio e análise da abordagem. |
| `main.py`        | Implementação da solução em Python.                                              |

## Convenção de Nomes

As pastas seguem o padrão:

```text
<problem_number>-<problem_name>
```

### Exemplos

```text
001-two_sum
013-roman_to_integer
125-valid_palindrome
```

## Objetivos

* Praticar resolução de problemas.
* Aprimorar conhecimentos em algoritmos e estruturas de dados.
* Desenvolver habilidades para entrevistas técnicas.
* Documentar soluções e aprendizados.
* Construir um histórico consistente de estudos e prática.
