# Solution

## Approach

To solve this problem, all it took was to compare the reversed string of `x` with the original string. If both strings are equal, then `x` is a palindrome.

## Complexity Analysis

| Metric           | Value |
| ---------------- | ----- |
| Time Complexity  | O(n)  |
| Space Complexity | O(n)  |

## What I Learned

* How string slicing can be used to reverse a string.
* How to compare strings to determine whether a value is a palindrome.
