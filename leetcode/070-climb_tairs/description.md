# Climbing Stairs

## Information

| Property   | Value                                          |
| ---------- | ---------------------------------------------- |
| Difficulty | Easy                                           |
| Topic      | Math, Dynamic Programming, Memoization         |
| Link       | https://leetcode.com/problems/climbing-stairs/ |

## Problem Summary

You are climbing a staircase with `n` steps. Each time, you can climb either 1 step or 2 steps.

Return the total number of distinct ways to reach the top of the staircase.

## Examples

### Example 1

```text
Input: n = 2
Output: 2
Explanation: There are two ways to climb to the top.
1. 1 step + 1 step
2. 2 steps
```

### Example 2

```text
Input: n = 3
Output: 3
Explanation: There are three ways to climb to the top.
1. 1 step + 1 step + 1 step
2. 1 step + 2 steps
3. 2 steps + 1 step
```

## Constraints

```text
1 <= n <= 45
```
