# Two Sum

## Information

| Property   | Value                                  |
| ---------- | -------------------------------------- |
| Difficulty | Easy                                   |
| Topic      | Array, Hash Table                      |
| Link       | https://leetcode.com/problems/two-sum/ |

## Problem Summary

Given an array of integers and a target value, find the indices of two numbers whose sum is equal to the target.

Each input is guaranteed to have exactly one valid solution, and the same element cannot be used more than once. The order of the returned indices does not matter.

## Examples

### Example 1

```text
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
```

### Example 2

```text
Input: nums = [3,2,4], target = 6
Output: [1,2]
```

### Example 3

```text
Input: nums = [3,3], target = 6
Output: [0,1]
```

## Constraints

```text
2 <= nums.length <= 10^4
-10^9 <= nums[i] <= 10^9
-10^9 <= target <= 10^9

Only one valid answer exists.
```
