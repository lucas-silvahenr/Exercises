# Reverse Integer

## Information

| Property   | Value                                          |
| ---------- | ---------------------------------------------- |
| Difficulty | Easy                                           |
| Topic      | Math                                           |
| Link       | https://leetcode.com/problems/reverse-integer/ |

## Problem Summary

Given a signed 32-bit integer, reverse its digits and return the resulting integer.

If reversing the integer causes the value to go outside the signed 32-bit integer range `[-2^31, 2^31 - 1]`, return `0`. Do not assume that 64-bit integers can be used.

## Examples

### Example 1

```text
Input: x = 123
Output: 321
```

### Example 2

```text
Input: x = -123
Output: -321
```

### Example 3

```text
Input: x = 120
Output: 21
```

## Constraints

```text
-2^31 <= x <= 2^31 - 1
```
