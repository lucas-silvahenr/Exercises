# Valid Perfect Square

## Information

| Property   | Value                                               |
| ---------- | --------------------------------------------------- |
| Difficulty | Easy                                                |
| Topic      | Math, Binary Search                                 |

## Problem Summary

Given a positive integer, determine whether it is a perfect square.

Return `true` if the number is a perfect square; otherwise, return `false`. You must solve the problem without using any built-in library function, such as `sqrt`.

## Examples

### Example 1

```text
Input: num = 16
Output: true
```

### Example 2

```text
Input: num = 14
Output: false
```

## Constraints

```text
1 <= num <= 2^31 - 1
```
